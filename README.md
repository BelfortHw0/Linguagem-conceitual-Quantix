# Linguagem Conceitual Quantix

Projeto desenvolvido para o curso de Engenharia de Software, na disciplina de Linguagens Formais. O trabalho apresenta uma linguagem de programação, incluindo seus comandos, sintaxe e funcionamento, bem como a definição de gramática, expressões regulares, autômatos, máquinas de Turing e documentação textual.
